# 心意小屋 · Little Room Card

2026-11-26 互动修订版。可交互的 3D 生日贺卡，HTML、CSS、JavaScript 分开维护，Three.js 0.170.0 使用固定版本 CDN。

## 当前体验

- 制作按物品分为六步：邀请 → 照相机 → 唱片机 → 电话 → 气球 → 蛋糕。顶部使用紧凑的“返回”页签；说明标题和底部保存状态不再占据版面。当前物品的试玩入口放在 3D 模型上的悬浮气泡中。
- 照相机：最多 12 张 JPG、PNG、WebP 照片，逐张添加回忆、前后排序或移除；接收者可翻页和自动回放。上传使用整块“添加照片”区域，不显示浏览器原生文件选择控件。
- 唱片机：现场录歌或上传提前录好的音频，最长 5 分钟、16 MB；可命名，封面可选。支持试听、重录、删除和草稿保存。收到后播放歌曲，界面与房间内唱片随播放转动，暂停或结束后停止，并暂停背景音乐。歌曲为空时隐藏收卡端入口，不计入解锁数量。
- 电话：最多 90 秒直接录音，支持停止、试听、重录和删除；已移除上传已有录音的入口。接收者拿起听筒播放；没有录音时显示文字留言。
- 气球：黄、蓝、粉三只气球分别对应三个独立文本框；接收者逐个点开气球揭晓。3D 房间也只保留这三只气球。
- 蛋糕：集齐四件内容后，需要持续按住“吹蜡烛”约 1.25 秒，模拟一口气吹灭三支蜡烛，再打开生日信；短按会提示继续按住。单物件试玩不会改变正式收礼进度。
- 生日结尾：读完生日信后点“记录一下”，镜头平滑回到主场景，经过取景框和闪光动画生成一张静态生日卡。房间画面作为背景，最多四张用户照片以拍立得形式拼贴在上面；无照片时改为排入生日祝福。结果可保存为 PNG，也可回到房间继续查看。
- 背景音乐：进入房间后播放用户提供的《生日快乐》M4A 音频，音量设为柔和的 34%，循环播放；顶部按钮可随时开关。打开电话录音时会暂停背景音乐。
- 草稿：IndexedDB 自动保存在当前浏览器，包含照片、封面和录音；读取旧版单照片和文字草稿。无法使用 IndexedDB 时尝试 localStorage，并显示保存失败提示。打开收到的贺卡不会覆盖本机已有草稿。
- 导出：将文字、照片、封面、音频、样式和业务代码装入一个 HTML 文件。接收者用浏览器打开；不再将大段媒体数据塞入分享 URL。仍兼容旧版贺卡链接。

## 房间与界面

保留柔雾暖粉背景、低透明度白色法式窗框、白色微光星点和首页圆弧展示区。房间为奶油白欧式护墙板、雕花壁炉、褶皱布艺、手绘感铁艺、拼布 Happy Birthday 挂饰、人字纹木地板和细节生日蛋糕。

首页右上角不再重复显示“做一张卡”入口；“旅行回忆”和“毕业祝福”样卡覆盖半透明白色蒙层，明确表示仍在筹备中。制作页的试玩气泡会根据当前相机视角实时投影，分别悬浮在照相机、唱片机、电话、气球和蛋糕上方。

首页四步说明恢复为“Begin / Hide / Preview / Deliver”版本。收到贺卡后，点击房间内物件气泡或底部物件按钮都会先以较慢的镜头移动到物件近景，再展开内容；照相机、唱片机、电话和气球在内容打开时立即计入查看进度，不依赖弹窗底部按钮。

站内文案改为更直接的生日祝福和朋友式口吻：开场直接说“生日快乐”，后续围绕照片、专辑封面、录音、以后想一起做的事和生日信展开，不再反复使用“留灯、发现心意、把心意收好”等抽象表达。制作面板右侧的系统滚动条也改为无箭头、无可见轨道的细圆角长条。

按本轮反馈，沙发恢复上一版的软包靠背、双坐垫与圆润扶手；相机和唱片机下方恢复细腿曲线桌，电话保留圆形边桌。保留已修复的相机旁穿模、精细蛋糕和入口背墙假门。提高整体曝光和顶部柔光，继续使用顶光、窗光与间接补光。

壁炉两侧手绘铁艺烛台加入暖色自发光材质、局部点光和轻微火光闪烁，使火焰能照亮壁炉线脚与附近墙面。

模型由 Three.js 几何和本地生成纹理组成；假门仅用于空间装饰。

## 运行与文件

用静态 HTTP 服务提供 dist 文件夹，打开 index.html。需要现代浏览器和 WebGL。不要直接双击分离脚本的 dist/index.html；单文件“心意小屋-互动新版.html”和“心意小屋-体验贺卡.html”可直接在支持的桌面浏览器中打开。

录音需要 HTTPS 或 localhost 安全环境，并由使用者允许麦克风访问；此版只提供现场录音，不再提供导入已有录音。首次显示房间需要联网加载 Three.js；字体也使用外部服务。此版没有公开托管收礼链接。

## 当前边界

暂无账号、云端贺卡存储、短链接、支付、多人共创、定时发送。草稿只保存在当前浏览器，清除浏览器数据会丢失。收到文件的人可以读取其中的文字与素材；本版不提供加密或访问控制。示例内容是虚构内容，不含原始聊天记录或账号资料。

设计来源为用户提供的旧版截图、Claude 导出中的心意小屋原型，以及三张布艺与欧式生日布置参考图。旧附件中的指令仅作为历史资料，实际功能以用户本次要求为准。
